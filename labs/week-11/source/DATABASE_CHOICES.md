## 3 คำถามที่ต้องตอบ

### 1. ทำไมโปรเจกต์นี้เลือก SQLite แทน MongoDB
```
เพราะ โครงข้อมูลมีความชัดเจน ทุกคำร้องมีรูปแบบเดียวกัน ทำให้ Schema กำหนดตารางและประเภทข้อมูลไว้ล่วงหน้าได้ง่าย
```
### 2. ถ้าวันหนึ่งต้องเปลี่ยนไป MongoDB จะกระทบชั้นไหนบ้าง
```

กระทบชั้น controller จากเดิมที่ไม่ต้องรอ  เพราะ service ใช้ SQLite ไฟล์จะอยู่ในเครื่อง เลยไม่จำเป็นต้องใช้ await เพราะไม่ต้องรอข้อมูลจากข้างนอก
ถ้า ใช้ MongoDB controller ต้องใช้ await เพราะ service ต้องรอข้อมูลจากข้างนอก
```

### 3. async จำเป็นเมื่อไร ไม่จำเป็นเมื่อไร
```
คำใบ้ — ต่างกันตรงที่ฐานข้อมูลอยู่ที่ไหน (ในเครื่อง vs คนละเครื่อง)
async จำเป็นเมื่อ service ทีการเรียกฐานข้อมูลจากภายนอกเลยต้องใช้ async และกำหนด await เสมอเพื่อให้ระบบรู้ว่าถ้าได้ผลลัพธ์ให้นำมาใส่ที่กำกับawaitไว้

```
