## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) | `RequestList.jsx : 7` | บรรทัดที่วนลูป `.map()` ตรง `<RequestCard/>` ไม่ได้ระบุ key prop ให้กับ component | ระบุ key prop ให้ component |
| 2 | ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `DashboardPage : 47-54` | เงื่อนไขในการ filter ผิด | เปลี่ยนให้ตรงเงื่อนไข |
| 3 | กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่ | `DashboardPage : 54` | `request.status !== statusFilter` ทำให้เงื่อนไขเป็นแสดง status ที่ไม่ใช่ status ที่เลือก | แก้เงื่อนไขให้เท่ากับ status ที่เลือก และเพิ่มการเช็ค Type ข้อมูล (`===`) |
| 4 | เปลี่ยน URL `REQ-001` → `REQ-002` แล้วข้อมูลไม่เปลี่ยน | `RequestDetailPage : 28` | `useEffect` ไม่ได้ใส่ `requestId` เข้าไปใน Dependency Array | ใส่ `requestId` เข้าไปใน Dependency Array ของ `useEffect` |
| 5 | กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย | `RequestDetailPage : 64` | `setRequests` ใช้ `requests` เดิม | เปลี่ยน `setRequests(requests)` เป็น `setRequests(nextRequests)` เพื่อใช้อาร์เรย์ที่อัปเดตแล้ว |
| 6 | กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า | `RequestDetailPage : 74` | ไม่ได้ใส่ `await` ให้กับฟังก์ชันแบบ `async` | เติม `await` เข้าไปตอนเรียกใช้ `resetRequests()` |
